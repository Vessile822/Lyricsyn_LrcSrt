lyricsync 歌詞自動對齊

丟一首歌和它的歌詞，自動產生 SRT 字幕，每一句的出現、消失時間對準人聲。全程在自己電腦上跑，不用帳號、不用上傳。

一、安裝（第一次） 二、使用 三、看結果 四、準度與小技巧 五、常見問題

一、安裝（只要做一次）

解壓縮後，雙擊 INSTALL.bat

請先將整個 ZIP 全部解壓縮到固定資料夾，再執行 INSTALL.bat。不需要尋找 Python 的 PATH 勾選框。

安裝程式會偵測 64 位元 Python 3.11／3.12；沒有時會嘗試 Python Install Manager 或下載 python.org 官方安裝程式。套件安裝到本資料夾的 .venv，並準備 FFmpeg。

出現 INSTALLATION SUCCESSFUL 才算完成。首次會下載數 GB，請保持視窗開著。套件檢查完成不代表 AI 模型已下載；模型會在第一次處理歌曲時下載。

失敗時請提供 install.log；歌曲處理失敗時提供 last_run.log。詳細步驟見「先看這裡.txt」。

二、使用

1

準備兩個檔案，檔名要一模一樣

歌曲檔，加上同名的歌詞 .txt。歌詞一行就是字幕的一句，你想怎麼分句就怎麼斷行。

2

拖到 DROP_HERE.bat 的圖示上放開

拖什麼都可以：歌曲檔、歌詞 txt、兩個一起、整個資料夾，或一次拖好幾首。

是拖到 DROP_HERE.bat 的圖示上，不是拖進打開後的黑色視窗。
3

等它跑完

黑色視窗會顯示進度，看到 done 就完成了，按任意鍵關掉。

三、看結果

歌曲旁邊會多出：

檔案是什麼
歌.srt字幕檔，可以直接匯入剪映、Premiere、DaVinci、YouTube 等。
歌_請檢查.txt只有發現可疑的句子才會出現，列出建議你看一眼的句子和原因（太短、太長、對不上）。
不用整首重看。打開 SRT 掃一下，再看「請檢查」列出的句子就好。

四、準度與小技巧

情況表現
中文歌最穩。實測 8 首，起唱點中位誤差約 0.02～0.08 秒，每首大約 1～3 句需要微調。
英文歌堪用。每首通常有幾句差 0.3～0.5 秒。
日文歌測試過一首，聽起來蠻準。韓文和其他語言程式能跑，但還沒驗證。
開頭有哼唱會自動判斷，大多能抓到真正的第一個字。
很長的拖音句尾可能比聲音早收一點，可自行拉長。

讓它更準的方法

  • 歌詞要跟實際唱的一樣。AI 歌常會偷改字、重複段落、多唱一句。txt 跟實際演唱差越多，越容易歪。
  • 重複的段落也要寫出來。副歌唱三次，txt 就寫三次。
  • 不確定語言時，可以在命令列加 --lang ja（日文）、--lang ko（韓文）、--lang en（英文）。平常會自動判斷。

五、常見問題

跑起來說「找不到 Python」

請確認使用修正版，完整解壓縮後重新執行 INSTALL.bat；它會自動偵測或安裝適用的 Python。失敗時提供 install.log。

說「缺歌詞 .txt」或「缺同名的音檔」

兩個檔名沒有完全一樣，連空格、全形半形都要相同。

沒有顯卡可以用嗎？

可以，只是慢很多：一首歌可能要 5～10 分鐘，有相容 NVIDIA 顯卡通常較快，依硬體與歌曲長度而異。

丟 mp3 / mp4 出現錯誤

修正版已準備 FFmpeg。請重新執行 INSTALL.bat，若仍失敗，提供 last_run.log。

同一首跑兩次結果一樣嗎？

一樣。同樣的歌和歌詞，每次產生的 SRT 都相同。

會上傳我的歌嗎？

不會。只有第一次會從網路下載公開的 AI 模型，之後歌曲和歌詞都只在你自己的電腦上處理。

使用的開源模型：Demucs（Meta，人聲分離）、Whisper（OpenAI，聽寫定位）、MMS（Meta，多語言逐字對齊），透過 stable-ts 與 transformers 執行。
