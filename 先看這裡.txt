LyricSync Windows 使用指引

【快速開始】
1. 雙擊執行 INSTALL.bat 進行一鍵配置（支援極速 uv 與 PyTorch CUDA 13.0）。
2. 將歌曲檔案（.mp3 / .wav / .m4a / .mp4）直接拖曳到 DROP_HERE.bat 圖示上即可！
3. 也可將現成的 .srt 字幕檔拖到 DROP_HERE.bat，將自動轉出 .lrc 動態歌詞。

【主要功能】
- 智慧三階歌詞：
  1. 優先匹配同名 .txt 歌詞檔。
  2. 若無 .txt，自動提取 Suno / Udio / ID3 音訊內嵌標籤，清洗結構標記並自動備份成 .txt。
  3. 若完全無歌詞，自動啟用 GPU Demucs 人聲分離 + Whisper 純聽寫模式，永不斷線。
- 動態歌詞輸出：
  - 1:1 逆向 ailrcgenerator 演算法，產出毫秒級 [mm:ss.xx] .lrc 動態歌詞與 .srt 字幕。
- 自動成果歸檔：
  - 完成品（音訊、.txt、.srt、.lrc）全套自動存入 songs 資料夾。

【系統相容性】
- 支援 Windows 10 / 11 (64-bit)。
- 支援 Python 3.11、3.12、3.13、3.14（推薦搭配 uv）。
- 支援 NVIDIA GPU（RTX 30 / 40 / 50 Blackwell 系列）Direct-to-CUDA 硬體加速，無顯卡時自動轉為 CPU 模式。

【故障排除】
- 安裝失敗：請查看 install.log
- 處理失敗：請查看 last_run.log
